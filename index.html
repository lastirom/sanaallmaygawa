My focus sits where engineering meets design: semantic markup, honest performance budgets, and typography that carries the message before a single image loads. I treat every requirement, even a midterm project, like a product someone will actually use.

Restaurant Ordering System

A Java Swing desktop POS for restaurant staff: menu with category filtering, running order totals, automatic combo discounts (10 to 20%), and formatted receipts. Built on solid OOP principles with an abstract MenuItem base class, a Composite Pattern for combo meals, and polymorphic price calculation that never needs a type check.
