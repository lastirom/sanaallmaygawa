01Hardware · IoT · 2026

Smart Hamster Habitat

A 432 L autonomous habitat where every routine is gated by a hard interlock that proves the animal is safe before any part moves. Concept led in CAD, trading owner convenience for animal autonomy: four corner cameras, climate sensing, IR night vision, and an actuation chain that puts safety first, only permitting motion when four independent checks return true.

02Desktop · ITEC 50 · 2026

Restaurant Ordering System

A Java Swing desktop POS for restaurant staff: menu with category filtering, running order totals, automatic combo discounts (10 to 20%), and formatted receipts. Built on solid OOP principles with an abstract MenuItem base class, a Composite Pattern for combo meals, and polymorphic price calculation that never needs a type check. Led Group 4 of 8 for the ITEC 50 Object Oriented Programming course.

Java 25SwingOOPAnt
